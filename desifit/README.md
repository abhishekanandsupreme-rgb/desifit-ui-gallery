# desifit

The main DesiFit Flutter app (dashboard, diet/budget/hydration trackers,
workout logging, calorie counter, Sasta protein calculator, AI chat).

See the repository root README for the monorepo layout, the CI model
(flutter analyze + flutter test gate this app on every push and PR), and
the security model (release-signing template at android/key.properties.example,
Firebase client-config tracking policy in firestore.rules).
